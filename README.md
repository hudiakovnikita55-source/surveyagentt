# surveyagent

Синтетические респонденты для анкет: набор реалистичных персон и скрипт, который заполняет анкету
(Google Forms или свой YAML) от имени каждой персоны так, как это сделал бы живой человек.

Первый набор: **100 персон, живущих в Европе и использующих ИИ в работе**
([`data/personas.json`](data/personas.json), табличный вид: [`data/personas.csv`](data/personas.csv)).

## Ответственное использование

Инструмент нужен для тестирования **своих** анкет и для синтетических исследований: проверить
формулировки и логику вопросов до запуска, прогнать аналитику и дашборды на реалистичных данных,
заранее прикинуть распределения ответов. Такие данные нужно помечать как синтетические.

Не отправляйте сгенерированные ответы в чужие опросы (исследования, дипломные работы, платные опросы,
общественные консультации): это подделка данных, и она нарушает правила Google. Поэтому:

- `submit` по умолчанию ничего не отправляет (dry run), для отправки нужен явный флаг `--send`;
- формы, требующие входа в Google (ограничение «1 ответ», только для организации, подтверждённый e-mail),
  не поддерживаются;
- запросы идут с честным User-Agent `surveyagent/...`, без прокси и маскировки под браузер;
- у персон адреса в зарезервированном домене `example.com`, чтобы не подставлять чужие реальные адреса.

## Установка

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY=sk-ant-...   # нужен только для режима LLM
```

Python 3.10+.

## Быстрый старт

```bash
# 1. Персоны (уже сгенерированы и лежат в data/; команда воспроизводит их точь-в-точь)
python -m surveyagent personas --count 100 --seed 42
python -m surveyagent stats              # распределения: страны, профессии, отношение к ИИ...
python -m surveyagent show P001 P017     # полный профиль персоны

# 2. Анкета: ссылка на Google Form (кнопка «Отправить» -> ссылка) или YAML-файл
python -m surveyagent inspect "https://docs.google.com/forms/d/e/<id>/viewform" --save forms/my_form.json
python -m surveyagent inspect examples/ai_at_work_survey.yaml

# 3. Ответы: сначала пробный прогон на 5 персонах, потом все 100
python -m surveyagent answer --form forms/my_form.json --limit 5 --out output/test.json
python -m surveyagent answer --form forms/my_form.json --out output/responses.json
python -m surveyagent answer --form forms/my_form.json --out output/responses.json --resume   # дозапустить упавшие

# без API-ключа: офлайн-режим (шаблонные открытые ответы, годится для проверки конвейера)
python -m surveyagent answer --form examples/ai_at_work_survey.yaml --mode offline

# 4. Отправка в свою форму: сначала посмотреть, что уйдёт, потом отправить
python -m surveyagent submit output/responses.json            # dry run: payload первого ответа
python -m surveyagent submit output/responses.json --send --delay 3
```

Результат `answer` сохраняется в двух видах: `responses.json` (анкета + ответы, из него работает `submit`)
и `responses.csv` (одна строка на респондента, столбцы как в выгрузке Google Sheets).

## Персоны

Генератор детерминированный (`--seed`), все поля согласованы между собой:

- **география**: 29 стран Европы, квоты пропорциональны населению с поправкой на распространённость ИИ
  на работе; города, родные языки, уровень английского; 12 человек из 100 с миграционной историей
  (поляки в Ирландии и Великобритании, украинцы в Польше и Испании, бразильцы в Нидерландах и Италии,
  русскоязычные жители Латвии и Эстонии и т. д.); имена и фамилии по правилам языка
  (Kowalski/Kowalska, Novák/Nováková, испанские двойные фамилии, исландские отчества);
- **работа**: 48 профессий в справочнике (от разработчиков и юристов до медсестёр, электриков и владельцев
  кафе), в текущей сотне встречаются 44; должность по стажу, отрасль, размер компании, формат работы,
  примерный доход по уровню зарплат страны;
- **ИИ**: инструменты (под профессию и страну: DeepL в неанглоязычных странах, Mistral во Франции,
  корпоративные ассистенты в крупных компаниях), частота, задачи, с какого года, кто платит, политика
  работодателя, обучение, отношение (энтузиаст / прагматик / осторожный / скептик), удовлетворённость,
  доверие, опасения, удачный и неудачный случай, раздражающая мелочь;
- **как человек заполняет анкеты**: вовлечённость (вдумчиво / обычно / на бегу), многословность, тон,
  привычка на шкалах (соглашаться, держаться середины, крайние значения), вероятность пропуска
  необязательных вопросов, раскрывает ли доход, особенности письма на английском для неносителей
  (типичные ошибки для родного языка), опечатки, «всё строчными».

## Как получаются «живые» ответы

- **Режим LLM** (по умолчанию): один запрос к Claude на персону. Модель получает профиль и анкету,
  отвечает строго по JSON-схеме, собранной из вопросов (варианты ответа только из списка, шкалы в
  диапазоне, все строки таблиц). Промпт требует согласованности с профилем, краткости как у реальных
  людей, конкретных деталей из жизни персоны и запрещает типичный «ИИ-стиль».
- **Проверка**: каждый ответ валидируется; если что-то не так, вопрос переотвечается офлайн-логикой
  и это записывается в `warnings`.
- **Опечатки и регистр** добавляются отдельно и детерминированно (`answering/humanize.py`), по привычкам
  конкретной персоны, потому что модели плохо изображают естественные опечатки.

По умолчанию используется модель `claude-opus-5` с адаптивным мышлением (`--effort medium`) и
серверным fallback-ом на случай отказа модели; другую модель можно задать через `--model`.
Системная часть промпта (правила + анкета) кешируется, меняется только профиль персоны. Стоимость
не измерялась на реальном прогоне; по оценке это порядка нескольких долларов за 100 анкет среднего
размера. Точное число токенов выводится в конце каждого прогона.

## Поддержка Google Forms

Форма читается из публичной страницы (`FB_PUBLIC_LOAD_DATA_`). Это неофициальный формат: если Google его
изменит, парсер придётся поправить.

- поддерживаются: короткий и развёрнутый ответ, один из списка, раскрывающийся список, несколько из
  списка, вариант «Другое», шкала, сетки (одиночный и множественный выбор), дата, время, сбор e-mail,
  многостраничные формы;
- не поддерживаются: загрузка файлов, формы с обязательным входом в Google, переходы между разделами
  в зависимости от ответа (сейчас считается, что респондент проходит все разделы по порядку);
- перед отправкой `submit --send` проверяет, что форма не изменилась с момента генерации ответов.

## Своя анкета в YAML

См. [`examples/ai_at_work_survey.yaml`](examples/ai_at_work_survey.yaml). Типы вопросов: `short_text`,
`paragraph`, `single_choice`, `dropdown`, `checkboxes`, `scale`, `rating`, `grid`, `checkbox_grid`,
`date`, `time`; `other: true` добавляет вариант «Другое».

## Структура

```
surveyagent/
  personas/geo.py         страны, города, языки, пулы имён
  personas/work.py        профессии, ИИ-инструменты, задачи, опасения, истории
  personas/generator.py   генератор персон, профиль для промпта
  questionnaire.py        модель анкеты, загрузка YAML/JSON, валидация ответов
  google_forms.py         разбор Google Form, сборка и отправка ответа
  answering/llm.py        ответы через Claude (схема, промпт, разбор)
  answering/heuristic.py  офлайн-ответы и подстраховка для LLM
  answering/humanize.py   опечатки, регистр, пунктуация
  answering/runner.py     параллельный прогон, проверка, сохранение, --resume
  export.py               CSV
  cli.py                  команды python -m surveyagent ...
data/personas.json|csv    100 персон
examples/                 пример анкеты
tests/                    python -m pytest
```
